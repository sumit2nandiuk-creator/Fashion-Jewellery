# Fashion Jewellery — logo

The emblem chosen for the shop: a maroon seal with an alpona-inspired gold border, an **FJ** monogram, the wordmark set in a high-contrast serif, and the Bengali line **বাংলার গহনা** beneath a hairline divider.

## Notes before print

- The artwork is a raster concept (PNG). Have it traced to vector (SVG/AI) before it is used on signage, boxes or foil stamping, so it stays sharp at large sizes.
- For the smallest uses — a 32 px favicon or a tiny stamp — use `logo-emblem-mark.png` and consider dropping the inner dot ring, which disappears below roughly 40 px.
- A one-colour version (all maroon on ivory, or all ivory on maroon) is worth having for receipts and low-cost printing.
