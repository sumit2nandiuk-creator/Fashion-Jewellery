## What the shop gets

**Homepage** — sticky header with wordmark, currency and cart, hero, collection teaser cards, workshop story, shipping and sizing, contact, footer.

**Collections page** — filter tabs with shareable category links, product grid, styling call to action.

**Product pages (3)** — image viewer, thumbnails, live price, specifications, related pieces, add to bag.

**Cart page** — quantity steppers, remove, live subtotal, WhatsApp order hand-off, empty state.

**Currency system** — INR, USD and GBP, chosen automatically from the visitor's country; a manual choice is saved.

**Policy pages (4)** — shipping, returns, privacy, terms.

**Responsive build** — phone, tablet, landscape and desktop layouts, category list inside the menu.

**Handover** — hand-written HTML, CSS and JavaScript with no build step, accessibility labels, README notes.
