## What the website includes

**Homepage** — announcement bar, sticky header with wordmark, currency picker and cart, hero, collection teaser cards, workshop story, shipping and sizing information, assurances strip, contact block, footer.

**Collections page** — filter tabs (All pieces, Earrings, Necklaces, Bangles & Rings), shareable deep links (`#earrings`), product grid, styling enquiry call-to-action.

**Product detail pages ×3** — full-screen image viewer, thumbnails, price in the selected currency, specifications, related pieces, add-to-bag.

**Cart page** — line items with quantity steppers, remove, live subtotal, WhatsApp order hand-off, empty state.

**Bag engine** — items stored in the browser, repeat adds merge into quantities, header badge, "+1" fly-to-cart animation and confirmation toast.

**Currency system** — INR, USD and GBP with a custom (non-native) dropdown, automatic selection from the visitor's country on first visit, manual choice remembered.

**Policy pages ×4** — shipping, returns, privacy, terms.

**Responsive behaviour** — mobile, tablet, landscape and desktop layouts; single-row wordmark; collapsible menu that lists the collection categories.

**Technical** — semantic HTML, hand-written CSS and vanilla JavaScript (no framework or build step), Google Fonts, SVG icons, favicon, metadata, accessibility labels, deployment on Cloudflare Pages, README handover notes.
